# Controle de Chamados

Aplicação web para registrar, organizar e acompanhar chamados realizados por data.

## Recursos

- Cadastro de atendimentos com solicitante, setor, OS, horários e status do chamado.
- Cálculo automático da duração de cada atendimento e dos totais por dia.
- Histórico organizado cronologicamente, com datas antigas no topo.
- Filtro para visualizar os chamados de uma data específica.
- Ordenação por solicitante, setor, status, início, final e duração.
- Salvamento automático no navegador, inclusive depois de fechar o site.
- Exportação de um dia ou de todo o histórico para Excel formatado.

## Como usar

1. Abra o arquivo `index.html` em um navegador.
2. Escolha a data no campo **Registrar atendimento para**.
3. Clique em **Adicionar chamado** e preencha os campos da tabela.
4. A duração e os totais são calculados automaticamente.
5. Use o filtro ou as setas dos cabeçalhos para localizar e ordenar os registros.
6. Use **Exportar tudo em Excel** para criar uma cópia formatada de todo o histórico.

## Salvamento dos dados

Os dados ficam armazenados localmente no navegador usado para abrir a aplicação. Eles continuam disponíveis depois de fechar e abrir o site novamente, no mesmo computador e navegador.

Para manter uma cópia de segurança ou transferir os registros para outro computador, exporte o histórico em Excel.
